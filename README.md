# German King

German King is a static, beginner-friendly German vocabulary study site. It includes A1 and A2 paths, flashcards, article and verb practice, a 10-question quiz, King's Word Quest, search, topic filters, and a paginated word list with a speaker button beside each entry. Pronunciation uses your browser's German speech voice when available.

## Open it

Keep `index.html`, `vocabulary.js`, and all `vocabulary-*.js` files together, then open `index.html` in a modern browser. The site has no build step and does not need a server for local use.

## Let other people use it

Upload the files in this folder to a static web host. GitHub Pages can serve them as a public website. Keep `index.html` and every `vocabulary-*.js` file together, plus `README.md`, `ATTRIBUTION.md`, `NOTICE-wordhoard.md`, and `LICENSE-CC-BY-SA-4.0.txt`, then enable Pages for the repository's default branch and root folder.

The prepared public address is `https://rohinoffical-design.github.io/german-king-study/`. This is a separate site from the older `german-king` page. The canonical link, sitemap, and `robots.txt` point to the prepared address; use a repository named `german-king-study` under `rohinoffical-design` when publishing these files.

The sitemap helps Google discover the site, but it does not guarantee search results. After publishing, add the address as a URL-prefix property in Google Search Console and submit `https://rohinoffical-design.github.io/german-king-study/sitemap.xml`. Google requires verified access before you can request indexing for the home page, and crawling can take days or weeks.

Every visitor gets their own progress in their browser. The site has no login or shared progress database.

## Vocabulary coverage

The library contains 100,000 translated German headwords plus curated learner examples. A1/A2 are the default study path. Frequency-ranked entries carry estimated CEFR labels; the additional dictionary entries are marked `Reference` because they do not have a reliable CEFR level. Reference entries may have fewer grammar details than the learner-focused words. Example sentences are included for the curated learning set.

See [ATTRIBUTION.md](ATTRIBUTION.md) for data sources and reuse terms.
